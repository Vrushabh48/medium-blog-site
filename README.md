# Medium a Blog Site
This project is the Clone of Medium, a Blog application. I have used Node.js and Express.js for the backend along with JWT-based Authentication and Zod for the Data Validation. The frontend is built with React and the design is with
Tailwind CSS.

The database used for this project is Postgres and also it utilizes Prisma as ORM along with Connection Pooling.

The backend is Hosted on CloudFlare workers and the frontend is deployed on Vercel. The Live Link for the Project: [Medium](https://medium-blog-site-gray.vercel.app/)

If you want to Clone the Project and have a Local Setup, then follow the below steps:

For Backend:
```
cd backend
npm install
npm run dev
```

For Frontend: 
```
cd frontend
npm install
npm run dev
```
